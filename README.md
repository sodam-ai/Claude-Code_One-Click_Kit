# Claude Code 원클릭 키트 (One-Click Kit)

> Windows에서 **번호와 화살표만으로** Claude Code를 설치·실행·관리하도록 도와주는 **한국어 도우미**입니다.
> 컴퓨터·AI·전자기기를 **처음 다루는 분**도 따라 할 수 있도록 어려운 말은 풀어서 적었습니다.

**한국어**: [README.md](./README.md) · [README.html](./README.html) / **English**: [README.en.md](./README.en.md) · [README.en.html](./README.en.html)

문서 기준일: 2026-09-21 · 라이선스: Apache License 2.0 · 비공식 도우미 (Anthropic과 무관)

> **시작하기 전에 꼭 읽어 주세요 (5가지)**
>
> 1. 이 키트는 **비공식**입니다. Claude Code는 Anthropic의 제품이고, 이 키트는 Anthropic과 제휴·보증·후원 관계가 없습니다.
> 2. Claude Code를 쓰려면 **유료 플랜 또는 계정**이 필요합니다. 무료 Claude.ai 계정만으로는 쓸 수 없습니다.
> 3. 이 키트는 **Windows 전용**입니다. (macOS·Linux·휴대폰에서는 쓸 수 없습니다.)
> 4. 메뉴 **[3] 시작하기**는 Claude Code를 켤 때 **컴퓨터의 모든 고정 디스크(C:, D: 등)를 "추가 작업 폴더"로 함께 넘깁니다.** 자세한 내용은 [13. 보안과 데이터 흐름](#13-보안과-데이터-흐름)에서 꼭 확인하세요.
> 5. 메뉴 **[8] 제거**는 파일을 **실제로 지웁니다.** 특히 "전부 지우기"는 되돌릴 수 없습니다.

## 1. 이 키트는 무엇인가요?

**Claude Code**는 Anthropic이 만든 AI 도구입니다. 컴퓨터 안에서 말(한국어 포함)로 시키면 파일 정리, 문서 요약, 간단한 프로그램 만들기 같은 일을 도와줍니다. 보통은 "검은 창(터미널)"에 명령어를 입력해서 켭니다.

**원클릭 키트**는 그 검은 창의 어려운 명령어를 **번호 메뉴로 바꿔 주는 작은 도우미**입니다. 파일 2개로 움직입니다.

- `Claude-Code_One-Click_Kit.bat` — 더블클릭하는 **실행 파일**
- `menu.ps1` — 한국어 메뉴가 들어 있는 **본체**

> 두 파일은 반드시 **같은 폴더**에 있어야 합니다. 하나만 옮기면 실행되지 않습니다.

### 처음 나오는 말 쉽게 풀이

| 말 | 쉬운 뜻 |
|---|---|
| 터미널 (검은 창) | 글자로 컴퓨터에 일을 시키는 창. 이 키트의 메뉴도 이 창에 나옵니다. |
| PowerShell | Windows에 원래 들어 있는 글자 명령 프로그램. 이 키트의 메뉴가 PowerShell 위에서 돌아갑니다. 따로 설치할 필요가 없습니다. |
| 폴더 | 파일을 담는 칸(디렉터리). Claude Code는 "어느 폴더에서 켰는지"를 기준으로 일합니다. |
| 로그인 | 내 계정임을 확인하는 절차. Claude Code는 처음 켤 때 인터넷 브라우저가 열려 로그인합니다. |
| 요금제 (플랜) | Claude의 유료 이용권 종류. Pro, Max, Team, Enterprise 등이 있습니다. |
| 설치 스크립트 | 프로그램을 내려받아 깔아 주는 작은 명령 묶음. 이 키트는 Anthropic 공식 주소의 것만 사용합니다. |
| 훅 (hook) | 다른 프로그램이 특정 일을 할 때 자동으로 같이 실행되는 작은 프로그램. 이 키트에서는 **선택 기능**([10장](#10-폴더-자동-등록-기능-선택))에서만 씁니다. |
| Node.js | 자바스크립트 프로그램을 실행하는 도구. 키트 본체에는 필요 없고, **선택 기능(10장)에만** 필요합니다. |

### 키트가 하는 일 / 하지 않는 일

| 하는 일 | 하지 않는 일 |
|---|---|
| 번호 메뉴를 보여 줍니다. | Claude Code를 **포함하거나 재배포하지 않습니다.** (실행할 때 공식 주소에서 내려받습니다.) |
| Claude Code 공식 설치 스크립트를 실행합니다. | 계정·결제·API 키를 **다루지 않습니다.** 로그인은 Claude Code가 브라우저로 처리합니다. |
| Claude Code를 원하는 폴더에서 켭니다. | 키트 스스로 **자동 업데이트되지 않습니다.** 새 키트는 직접 다시 받아야 합니다. |
| 업데이트·진단·버전 확인 명령을 대신 실행합니다. | macOS·Linux를 지원하지 않습니다. |
| Claude Code를 지웁니다. (선택 시) | 사용자의 정보를 **수집하거나 외부로 보내는 코드가 없습니다.** (설치 스크립트를 내려받는 요청 1건 제외, [13장](#13-보안과-데이터-흐름) 참고) |

## 2. 사전 준비물과 필요 프로그램

### 2-1. 준비물 체크리스트

- ☐ Windows 10 (1809 이상) 또는 Windows 11 컴퓨터
- ☐ 인터넷 연결 (설치·로그인·사용에 모두 필요)
- ☐ 인터넷 브라우저 (로그인 화면을 여는 데 사용)
- ☐ **Claude 유료 플랜 또는 계정** (아래 표 참고)
- ☐ 이 키트 파일 (3장에서 받는 방법을 설명합니다)

### 2-2. 필요한 것과 필요 없는 것

| 항목 | 필수 여부 | 설명 |
|---|---|---|
| Windows 10 1809 이상 / Windows 11 | **필수** | Claude Code의 공식 요구사항입니다. 키트는 이 PC의 Windows 11에서 시험했고, Windows 10에서의 동작은 **미확인**입니다. |
| 메모리(RAM) 4GB 이상, x64 또는 ARM64 프로세서 | **필수** | Claude Code의 공식 요구사항입니다. |
| 인터넷 연결 | **필수** | |
| Claude 계정 (Pro, Max, Team, Enterprise 또는 Console) | **필수** | 무료 Claude.ai 플랜에는 Claude Code가 포함되지 않습니다. |
| Anthropic 지원 국가에 있을 것 | **필수** | Anthropic 공식 요구사항입니다. 지원 국가 목록은 [anthropic.com/supported-countries](https://www.anthropic.com/supported-countries)에서 확인하세요. |
| Windows PowerShell 5.1 | 필수 (기본 내장) | Windows 10·11에 들어 있어 **따로 설치할 필요가 없습니다.** |
| Node.js | **필요 없음** | Claude Code와 키트 본체에는 필요하지 않습니다. (선택 기능 10장에만 필요) |
| Git for Windows | 선택 | 있으면 Claude Code가 Bash 도구를 쓸 수 있습니다. 없으면 PowerShell을 대신 사용하며, 없어도 정상 작동합니다. |
| 관리자 권한 | **필요 없음** | Claude Code 설치에 관리자 권한이 필요하지 않다고 공식 문서에 적혀 있습니다. |

> 위 요구사항은 Anthropic 공식 설치 문서(<https://code.claude.com/docs/en/setup>)를 **2026-09-20에 확인**한 내용입니다. Anthropic이 바꿀 수 있으니 설치 전에 공식 문서도 한 번 확인하세요.

**검은 창이 부담스러우면?** 마우스로 쓰는 **Claude 데스크톱 앱**도 있습니다. ([claude.com/download](https://claude.com/download)) 이 경우 키트는 필요하지 않고, 같은 계정 조건이 적용됩니다.

## 3. 다운로드 방법

### 3-1. 키트 받기

저장소 주소: <https://github.com/sodam-ai/Claude-Code_One-Click_Kit>

**방법 A. ZIP으로 받기 (가장 쉬움)**

1. 위 주소를 브라우저로 엽니다.
2. 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
3. 받은 ZIP 파일을 **오른쪽 클릭 → "압축 풀기"** 로 풉니다. (ZIP 안에서 바로 실행하면 `menu.ps1`을 못 찾아 실패합니다.)
4. 압축을 푼 폴더 안에 `Claude-Code_One-Click_Kit.bat`과 `menu.ps1`이 **함께** 있는지 확인합니다.

**방법 B. git으로 받기 (Git을 아는 분)**

```
git clone https://github.com/sodam-ai/Claude-Code_One-Click_Kit.git
```

**폴더 위치 권장:** 짧은 영문 경로(예: `C:\ClaudeKit`)를 권장합니다. 한글·공백이 든 경로도 따옴표로 감싸 처리하도록 만들어져 있지만 모든 경우를 시험하지는 않았으므로, 문제가 생기면 짧은 영문 경로로 옮겨 보세요.

> **받은 파일이 이 문서와 다를 수 있습니다.** 저장소의 릴리스 `v2.0.0`(2026-09-21)부터 이 문서가 설명하는 폴더 고르기·정렬·제거 메뉴 안전 수정이 들어 있습니다. `v1.0.0`(2026-04-20)은 **초기 버전**이라 이 기능들이 없습니다. 받은 뒤 [3] 시작하기를 눌렀을 때 **"어느 폴더에서 시작할까요?"** 화면이 나오면 이 문서와 같은 버전입니다. 나오지 않으면 더 오래된 버전이니 **Releases 페이지에서 최신 릴리스**를 받으세요.

**Windows가 경고를 띄울 때**

- 처음 실행하면 **"Windows의 PC 보호"** 창이 뜰 수 있습니다. 인터넷에서 받은 실행 파일에는 흔히 나오는 경고입니다. **추가 정보 → 실행**을 누르세요. 출처가 불안하면 실행하지 마세요.
- 그래도 막히면: 파일(`.bat`, `menu.ps1`)을 오른쪽 클릭 → **속성** → 아래쪽 **"차단 해제"** 체크 → 확인.

### 3-2. Claude Code 받기 (자동)

- 키트의 **[1] 설치하기**를 누르면 **Anthropic 공식 주소** `https://claude.ai/install.ps1`에서 설치 스크립트를 내려받아 바로 실행합니다. 사용자가 따로 받을 것은 없습니다.
- 키트 없이 직접 설치하려면 (Anthropic 공식 안내, PowerShell):

```
irm https://claude.ai/install.ps1 | iex
```

- 다른 공식 방법으로 WinGet(`winget install Anthropic.ClaudeCode`)도 있습니다. 단, WinGet으로 설치한 것은 **자동 업데이트되지 않고**, 키트의 [8] 제거로 **지워지지 않습니다.** (WinGet으로 지우세요.)

## 4. 설치 방법

### 4-1. Claude Code 설치 (처음 한 번)

1. `Claude-Code_One-Click_Kit.bat`을 **더블클릭**합니다. 검은 창에 한국어 메뉴가 나옵니다.
2. **↑↓ 화살표로 `1 설치하기`를 고르고 Enter**를 누릅니다. (숫자 `1` 키를 눌러도 됩니다.)
3. 화면에 필요한 것(유료 플랜, 인터넷)과 설치 주소가 나옵니다. 읽은 뒤 **Enter**를 누르면 설치가 시작됩니다. (취소하려면 창을 닫으세요.)
4. **1~2분** 기다립니다. `설치 완료!`가 보이면 성공입니다.
5. `설치는 됐지만 이 창에서 아직 인식이 안 돼요`가 보이면 **창을 닫고 키트를 다시 실행**하세요. (설치 직후 흔한 일이며 정상입니다.)

이미 설치되어 있으면 `이미 설치되어 있어요.`라고 알려 주고 **다시 설치하지 않습니다.**

### 4-2. (선택) 폴더 자동 등록 기능 설치

Claude에게 채팅으로 `cd 폴더경로`를 시켜 이동한 폴더가 **[3] 시작하기 목록에 자동으로 뜨게** 하고 싶을 때만 설치합니다. 자세한 설명은 [10장](#10-폴더-자동-등록-기능-선택)입니다.

1. **Node.js**를 설치합니다. (<https://nodejs.org>)
2. 키트 폴더의 `tools\cd-hook` 폴더로 들어가 `install-cd-hook.cmd`를 **더블클릭**합니다.
3. 마지막에 `[완료]`와 `자체 테스트: 통과`가 보이면 성공입니다.
4. **새 Claude Code 세션**을 열어야 적용됩니다.

## 5. 빠른 시작 (3단계)

1. `Claude-Code_One-Click_Kit.bat`을 **더블클릭**합니다.
2. **`1` 설치하기**를 골라 Claude Code를 설치합니다. *(처음 한 번만)*
3. **`3` 시작하기**를 고릅니다. 맨 위 **`D 경로 직접 입력`** 에서 Enter를 눌러 폴더 경로를 붙여넣거나, 목록에서 폴더를 고른 뒤 Enter를 누릅니다. 처음에는 **브라우저 로그인**이 한 번 뜹니다. → 끝!

그 뒤로는 한국어로 시키면 됩니다. 예) `이 폴더에 있는 사진을 날짜별로 정리해줘`

## 6. 실행 방법

**평소에 켜는 방법 (매번)**

1. `Claude-Code_One-Click_Kit.bat`을 더블클릭합니다.
2. 메뉴에서 **`3` 시작하기**를 고릅니다.
3. **"어느 폴더에서 시작할까요?"** 목록에서 원하는 폴더를 고르고 Enter를 누릅니다. (고르는 방법은 [7-3](#7-3-폴더-고르기-화면-3번))
4. 그 폴더가 **처음 여는 곳**이면 안내가 뜹니다. 안내를 읽고 [7-4](#7-4-이-폴더를-믿나요-창-처음-여는-폴더에서)대로 진행하세요.
5. Claude Code가 켜집니다. **처음이면 브라우저가 열려 로그인**합니다. 평소 쓰던 방식으로 로그인하면 됩니다.

**끝내는 방법:** Claude 안에서 `/exit`(또는 `/quit`)를 입력합니다. 키트 메뉴로 돌아오면 **Enter**를 눌러 계속하고, 메뉴에서 **Q**(또는 Esc)로 키트를 닫습니다.

**메뉴가 켜지지 않을 때:** 검은 창에 `Could not start the menu`가 나오면 `.bat`과 `menu.ps1`이 **같은 폴더**에 있는지 확인하세요. 자세한 해결은 [14장](#14-문제오류-대처)입니다.

## 7. 사용 방법

### 7-1. 메뉴 조작법

| 누르는 키 | 하는 일 |
|---|---|
| `↑` `↓` | 항목을 고릅니다. (끝에서 넘기면 반대편으로 이어집니다.) |
| `Enter` | 고른 항목을 실행합니다. |
| 숫자 `1`~`8` | 그 번호를 **바로** 실행합니다. |
| `Q` 또는 `Esc` | 키트를 닫습니다. |

화면 맨 위에는 `상태  설치됨`(또는 `아직 설치 안 됨`)과 현재 Windows 사용자 이름이 표시됩니다.

### 7-2. 메뉴 전체 설명

| 번호 | 이름 | 하는 일 |
|:---:|---|---|
| **1** | 설치하기 | Claude Code를 설치합니다. 이미 있으면 건너뜁니다. |
| **2** | 로그인·계정 안내 | 어떤 계정이 필요한지, 로그인은 어떻게 하는지 안내합니다. (읽기만 함) |
| **3** | 시작하기 | 폴더를 고른 뒤 Claude Code를 켭니다. |
| **4** | 도움말·명령어 | Claude 안에서 쓰는 명령어를 보여 줍니다. (읽기만 함) |
| **5** | 업데이트 | `claude update`를 실행합니다. |
| **6** | 진단·문제 해결 | `claude doctor`로 설치 상태를 점검하고 자주 묻는 문제를 보여 줍니다. |
| **7** | 버전 확인 | `claude --version`을 실행합니다. |
| **8** | 제거 | Claude Code를 지웁니다. ([12장](#12-제거-방법) 참고) |
| **Q** | 종료 | 키트를 닫습니다. |

Claude Code가 설치되어 있지 않으면 3·5·6·7번은 `아직 설치가 안 돼 있어요`라고 알려 주고 **1번을 먼저 하라고 안내**합니다.

### 7-3. 폴더 고르기 화면 (3번)

Claude Code는 **켠 폴더 안에서** 일합니다. 그래서 켜기 전에 폴더를 고릅니다.

```
  ══════ 어느 폴더에서 시작할까요? ══════

   ▶ [D ]  경로 직접 입력                          목록에 없는 폴더
     [0 ]  홈 폴더                                지금까지 방식
     [1 ]  (최근 작업한 폴더 이름)
     [2 ]  (최근 작업한 폴더 이름)

   고른 곳 :  (지금 고른 줄의 전체 경로)
   ↑↓ 로 고르고 Enter.   숫자·D 키는 그 줄로 이동.   S: 정렬 전환.   취소는 Esc.   [정렬: 수정 최신순]
```

(화면 모양은 예시입니다. 실제 폴더 이름과 색은 다를 수 있습니다.)

**처음 열면 커서는 맨 위 `D 경로 직접 입력` 줄에 있습니다.** 새 프로젝트를 시작할 때는 그대로 **Enter → 폴더 경로 붙여넣기**만 하면 됩니다. 홈 폴더로 시작하려면 `↓`를 한 번 누르거나 `0` 키를 누른 뒤 Enter를 누르세요.

> **왜 홈 폴더에서 켜고 `cd`로 옮기면 안 되나요?** 이 키트를 만들며 확인한 바로는, Claude 안에서 `cd`로 작업 폴더를 옮겨도 **다음 명령에서 원래 폴더로 되돌아갑니다.** (Claude Code 버전에 따라 달라질 수 있습니다.) 그래서 **처음부터 일할 폴더에서 켜야** 하고, 새 프로젝트 폴더는 `D` 줄로 들어가는 것이 가장 확실합니다.

| 누르는 키 | 하는 일 |
|---|---|
| `↑` `↓` | 줄을 고릅니다. |
| `Enter` | 고른 폴더에서 Claude Code를 켭니다. |
| 숫자, `D` | 그 번호의 줄로 **이동만** 합니다. (바로 실행하지 않으니 Enter로 확정하세요. 10번 이상은 두 자리 숫자라서 실수를 막기 위한 것입니다.) |
| `Home` `End` | 맨 위 / 맨 아래로 이동합니다. |
| `PageUp` `PageDown` | 한 화면씩 넘깁니다. |
| `S` | **정렬 방식을 바꿉니다** (아래 표). |
| `Esc` | 취소하고 메뉴로 돌아갑니다. |

**목록에 뜨는 폴더는 어디서 가져오나요?**

- 이전에 Claude Code를 **실제로 켰던 폴더**(Claude Code가 기록해 둔 `.claude.json`의 프로젝트 목록)
- (선택 기능을 설치했다면) 채팅에서 `cd`로 이동한 폴더 (`menu-extra-folders.txt`, [10장](#10-폴더-자동-등록-기능-선택))
- 목록에서 자동으로 **빠지는 것**: 내 사용자 폴더 자체, Windows 폴더, 이미 지워진 폴더, 중복.
- 줄이 화면보다 길면 `▲ 위에 더 있어요` / `▼ 아래에 더 있어요`가 나오며 **스크롤**됩니다. 개수 제한은 없습니다.
- 목록에 없는 폴더(새 프로젝트 포함)는 맨 위 **`D` 줄**에서 Enter를 누르고 **폴더 경로를 붙여넣으세요.** (그냥 Enter를 누르면 취소됩니다. 없는 폴더면 `그런 폴더가 없어요`라고 알려 줍니다.)

**`S` 키 정렬 방식 (누를 때마다 다음으로 순환)**

| 순서 | 이름 | 기준 |
|:---:|---|---|
| 1 | 수정 최신순 (기본) | 폴더의 "수정한 날짜"가 최근인 것부터 |
| 2 | 수정 오래된순 | 수정한 날짜가 오래된 것부터 |
| 3 | 생성 최신순 | 폴더를 만든 날짜가 최근인 것부터 |
| 4 | 생성 오래된순 | 만든 날짜가 오래된 것부터 |
| 5 | 이름순 | 폴더 이름 가나다·ABC순 |
| 6 | 이름역순 | 이름 반대순 |

- 정렬을 바꿔도 **지금 고른 폴더는 그대로 유지**되고, `경로 직접 입력`은 항상 맨 위, 그 아래 `홈 폴더`는 항상 둘째 줄에 고정되어 있습니다. (정렬은 그 아래 폴더들에만 적용됩니다.)
- 정렬 방식은 **저장되지 않습니다.** 3번을 다시 열면 항상 "수정 최신순"으로 시작합니다.
- "수정한 날짜"는 Windows가 폴더에 기록하는 값으로, 보통 폴더 **바로 안에** 파일이 생기거나 지워질 때 바뀝니다.

> **화살표가 안 먹는 특수한 환경**(자동 실행 등 입력이 연결된 경우)에서는 자동으로 **번호를 적는 방식**으로 바뀝니다. 번호를 입력하고 Enter를 누르며, 그냥 Enter는 `0번 홈 폴더`입니다.

### 7-4. "이 폴더를 믿나요?" 창 (처음 여는 폴더에서)

Claude Code는 처음 여는 폴더에서 **"이 폴더를 믿나요?"** 라고 한 번 묻습니다. 그런데 **기본 선택이 `No, exit`(끝내기)** 라서, 모르고 Enter만 누르면 그냥 꺼집니다. 그래서 키트가 미리 안내합니다.

1. `[이 폴더는 Claude 로 처음 여는 곳이에요]` 안내가 나옵니다.
2. 잠시 뒤 Claude의 질문 창이 뜨면 **아래 화살표(↓)로 `Yes, I trust this folder`를 고르고 Enter**를 누릅니다.
3. 한 번 해 두면 그 폴더는 다음부터 묻지 않습니다.

> 믿을 수 없는 출처에서 받은 폴더라면 `Yes`를 누르지 마세요. Claude가 그 폴더 안의 파일을 읽고 실행할 수 있게 됩니다.

### 7-5. Claude에게 시키는 방법

로그인 후에는 명령어를 외울 필요 없이 **말하듯이** 시키면 됩니다.

- `이 폴더에 있는 사진들 날짜별로 정리해줘`
- `간단한 메모장 프로그램 하나 만들어줘`
- `이 파일이 무슨 내용인지 요약해줘`

잘 쓰는 요령:

- **구체적으로** 말하세요. ("정리해줘"보다 "사진을 날짜별 폴더로 옮겨줘")
- **한 번에 한 가지**씩 시키세요.
- 파일을 지우거나 옮기는 일은 시키기 전에 **중요한 파일을 복사해 두세요.** AI도 실수할 수 있습니다.
- Claude가 "이 작업을 해도 될까요?"라고 물으면 **내용을 읽고** 허용하세요.

## 8. 작동 방법

키트가 내부에서 하는 일을 순서대로 적었습니다. 코드를 몰라도 읽을 수 있게 풀었습니다.

1. **`.bat` 실행:** `Claude-Code_One-Click_Kit.bat`이 `powershell -NoProfile -ExecutionPolicy Bypass -File menu.ps1`을 실행합니다. (한국어를 안전하게 표시하려고 메뉴는 PowerShell 쪽에 있고, `.bat`은 영어(ASCII)만 씁니다. `Bypass`는 **이 창 한 번에만** 적용되는 설정이며 Windows 설정을 바꾸지 않습니다.)
2. **PATH 보강:** 설치 직후에도 `claude`를 찾을 수 있도록, 이 창에 한해 `%USERPROFILE%\.local\bin`과 `%APPDATA%\npm`을 검색 경로에 더합니다.
3. **메뉴 표시:** 화살표·숫자 입력을 받아 선택한 기능을 실행합니다.
4. **[1] 설치:** `claude`가 있는지 먼저 확인하고, 없으면 공식 설치 스크립트를 내려받아 실행합니다.
5. **[3] 시작:**
   1. 고정 디스크 목록을 만듭니다. (예: `C:/`, `D:/`)
   2. 폴더 목록을 만들고 사용자가 폴더를 고릅니다.
   3. 그 폴더로 이동(`Set-Location`)합니다. 실패하면(폴더가 지워졌거나 이름이 바뀜) 멈추고 알려 줍니다.
   4. 그 폴더를 Claude가 이미 "믿는다"고 기록했는지 **읽기만** 해서 확인하고, 아니면 7-4 안내를 보여 줍니다.
   5. `claude --add-dir <고정 디스크들>`을 실행합니다. (디스크를 못 찾으면 그냥 `claude`)
6. **[5][6][7]:** 각각 `claude update`, `claude doctor`, `claude --version`을 그대로 실행합니다.
7. **[8] 제거:** 12장을 보세요.

키트가 하는 일은 여기까지입니다. **AI가 답하는 일 자체는 Claude Code(Anthropic)가 합니다.**

## 10. 폴더 자동 등록 기능 (선택)

### 10-1. 왜 필요한가요?

3번 목록은 "Claude Code를 **실제로 켰던** 폴더"를 보여 줍니다. 그런데 이미 켜진 Claude와 채팅하다 `cd 폴더경로`로 이동해 작업한 폴더는 그 기록에 남지 않아서 목록에 안 뜹니다. 이 선택 기능은 그런 폴더를 목록에 **자동으로 더해 줍니다.**

### 10-2. 어떻게 동작하나요?

- Claude Code의 **훅(hook)** 기능으로 Bash·PowerShell 명령이 실행되기 직전에 작은 프로그램(`cd-folder-register.cjs`)이 함께 돌아갑니다.
- 그 프로그램은 명령 글자에서 `cd`·`Set-Location`(`sl`) 뒤의 **드라이브 문자가 있는 폴더 경로**를 찾아, 실제로 있는 폴더면 `%APPDATA%\claude-code\menu-extra-folders.txt`에 한 줄 더합니다. (이미 있으면 더하지 않음)
- **명령 실행을 막거나 바꾸지 않습니다.** 어떤 오류가 나도 조용히 통과시킵니다.
- 명령마다 약 **0.1초**가 더 걸립니다. (작성자 PC 측정 평균 약 95ms)

### 10-3. 등록되지 않는 경로 (의도된 제외)

- 내 사용자 폴더, Windows 폴더, `node_modules` 안, Claude 설정 폴더, `Temp\claude` 임시 폴더
- 없는 폴더, 파일, 드라이브 문자가 없는 상대경로 (`cd ..` 등)
- `echo`, `printf`, `Write-Host`, `Write-Output`, `cat`, `type`으로 **시작하는** 명령 (글자를 출력할 뿐 이동이 아니므로)

### 10-4. 설치기가 하는 일 (안전장치)

- 훅 파일을 Claude 설정 폴더(`CLAUDE_CONFIG_DIR` 환경변수, 없으면 `%USERPROFILE%\.claude`)의 `hooks`에 복사합니다.
- 같은 설정 폴더의 `settings.json`에 훅 2개(Bash, PowerShell)를 **덧붙이기만** 합니다. 기존 설정은 그대로입니다.
- 수정 **전에 백업**(`settings.json.bak-cd-hook-날짜시간`)을 만들고, 수정 **후에 다시 읽어 검증**하며, 이상이 있으면 **자동으로 원래대로 복구**합니다.
- 여러 번 실행해도 결과가 같습니다. (이미 등록돼 있으면 "이미 등록"이라고만 알림)
- `settings.json`이 깨졌거나 형식이 예상과 다르면 **손대지 않고 멈춥니다.**
- 마지막에 임시 폴더로 자체 테스트를 합니다. (실제 등록 파일은 건드리지 않음)
- `.claude.json`은 **절대 수정하지 않습니다.**

**되돌리기:** `settings.json.bak-cd-hook-날짜시간` 파일을 `settings.json`으로 덮어쓰면 설치 전 상태로 돌아갑니다.

### 10-5. 한계 (알아 두세요)

- 이 기능은 **이 PC의 Claude 설정에만** 적용됩니다. 다른 PC에서는 그 PC에서 다시 설치해야 합니다.
- Claude Code가 훅 기능을 바꾸면 동작하지 않을 수 있습니다. 목록에 안 뜨면 [14장](#14-문제오류-대처)을 보세요.
- 훅은 **모든 프로젝트의 모든 Bash·PowerShell 명령**에서 실행됩니다. (명령 글자만 읽고 저장하지는 않습니다.)

```
        │
        ▼
  /exit 입력 ─▶ 메뉴로 돌아옴 ─▶ Q 로 종료
```

**평소에 쓰는 사람**

```
.bat 더블클릭 ─▶ [3] 시작하기 ─▶ 폴더 고르기 ─▶ Claude 사용 ─▶ /exit ─▶ Q
```

**가끔 하는 관리**

```
[5] 업데이트  /  [6] 진단  /  [7] 버전 확인  /  [8] 제거
```

## 12. 제거 방법

### 12-1. 키트에서 지우기 (메뉴 8번)

1. 메뉴에서 **`8` 제거**를 고릅니다.
2. 세 가지 중에서 고릅니다.
   - **[1] 프로그램만 지우기** — 설정·로그인·대화 기록은 **남깁니다.** (나중에 다시 설치해 이어 쓸 수 있음)
   - **[2] 전부 지우기** — 프로그램을 지운 **뒤** 설정·로그인·대화 기록까지 지웁니다. **되돌릴 수 없습니다.**
   - **[3] 취소**
   - 그 밖의 입력(예: `9`, `n`)은 **아무것도 지우지 않고** `그 번호는 없어요`라고 알린 뒤 돌아갑니다.
3. **[2]를 골라도 프로그램은 먼저 바로 지워집니다.** 그다음에 `[경고] 설정·로그인·대화기록을 모두 삭제합니다. 정말 진행할까요?`라고 **Y/N**으로 물으며, 이 질문은 **설정 삭제에만** 해당합니다. `N`이면 설정과 기록은 남지만 프로그램은 이미 지워진 뒤입니다.

**지워지는 위치**

| 무엇 | 위치 | [1] | [2] |
|---|---|:---:|:---:|
| 프로그램 | `%USERPROFILE%\.local\bin\claude.exe` | 지움 | 지움 |
| 프로그램 파일들 | `%USERPROFILE%\.local\share\claude` | 지움 | 지움 |
| npm 전역 패키지 | `npm uninstall -g @anthropic-ai/claude-code`를 실행합니다. (화면에는 아무것도 보이지 않도록 출력을 숨깁니다.) | 지움 | 지움 |
| 설정·로그인·대화 기록 | `%USERPROFILE%\.claude` 폴더, `%USERPROFILE%\.claude.json` 파일 | 남김 | Y면 지움 |

**키트가 지우지 않는 것**

- WinGet 등 다른 방법으로 설치한 Claude Code (그 방법으로 지우세요)
- VS Code 확장, JetBrains 플러그인, 데스크톱 앱 (각각 따로 지우세요. 이들도 `%USERPROFILE%\.claude`를 쓰므로 남아 있으면 폴더가 다시 생길 수 있습니다.)
- Claude 설정 폴더를 다른 곳으로 옮겨 쓰는 경우의 그 폴더 (`%APPDATA%\claude-code` 등)
- **키트 파일 자체**, `menu-extra-folders.txt`, 선택 기능의 훅과 `settings.json`의 훅 항목

### 12-2. 선택 기능(폴더 자동 등록) 지우기

1. `settings.json`에서 `cd-folder-register.cjs`가 들어 있는 항목 2개(Bash, PowerShell)를 지우거나, 설치 전 백업 파일(`settings.json.bak-cd-hook-날짜시간`)로 덮어씁니다.
2. 원하면 `hooks\cd-folder-register.cjs`와 `%APPDATA%\claude-code\menu-extra-folders.txt`, `cd-hook-errors.log`도 지웁니다.

## 13. 보안과 데이터 흐름

이 장은 "무엇이 실행되고, 무엇을 읽고, 무엇이 밖으로 나가는지"를 솔직하게 적었습니다. **키트 코드(`Claude-Code_One-Click_Kit.bat`, `menu.ps1`, `tools\cd-hook`)를 직접 읽어 확인한 내용**입니다.

### 13-1. 데이터 흐름 한눈에 보기

```
 [ 내 컴퓨터 ]                                         [ 인터넷 ]
 키트(.bat, menu.ps1) ──(설치할 때만 1회)────────────▶ claude.ai/install.ps1  (설치 스크립트 내려받기)
        │
        └─ claude 실행 ───────────────────────────▶ Anthropic 서비스  (Claude Code가 직접 통신)
                 ▲
   (키트는 이 통신에 관여하지 않음)
```

- **키트가 직접 인터넷에 접속하는 곳은 딱 하나**입니다. [1] 설치하기에서 `https://claude.ai/install.ps1`을 내려받는 것입니다.
- 키트 코드에는 사용자의 파일·대화·계정 정보를 **모으거나 외부로 보내는 부분이 없습니다.**
- Claude Code를 켠 뒤의 통신(대화 내용 전송 등)은 **Claude Code 본체(Anthropic)** 가 합니다. 무엇이 어떻게 처리되는지는 이 문서가 보증하지 않으며 Anthropic의 약관·개인정보 안내를 따릅니다.

### 13-2. 키트가 읽는 것 / 쓰는 것

| **폴더를 믿는다(Yes, I trust)** | 그 폴더의 파일을 Claude가 읽고 실행할 수 있게 됩니다. | 출처를 아는 폴더에서만 `Yes`를 고르세요. |

### 13-4. 기록(로그)과 민감정보

- 훅이 오류로 실패하면 `%APPDATA%\claude-code\cd-hook-errors.log`에 **시각과 오류 종류만** 한 줄 남깁니다. 명령 내용은 남기지 않으며, 파일이 50KB를 넘으면 더 쓰지 않습니다.
- `menu-extra-folders.txt`에는 **내 폴더 경로**가 들어 있습니다. 오류를 신고하거나 화면을 공유할 때 **경로(사용자 이름 포함)를 가리세요.**
- 키트와 문서에는 API 키·비밀번호·토큰을 **저장하지 않습니다.** 저장소를 올리기 전에 이런 값이 없는지 확인했습니다. (작성 시점 검사 기준)
- 오류를 신고할 때 **계정 정보, `.claude.json` 내용, 비밀번호를 붙여 넣지 마세요.**

## 14. 문제·오류 대처

먼저 메뉴 **`6` 진단·문제 해결**을 눌러 보세요. `claude doctor`가 원인을 알려 줍니다.

### 14-1. 키트 실행·설치 문제

| 증상 | 원인과 해결 |
|---|---|
| `Could not start the menu` | `.bat`과 `menu.ps1`이 **같은 폴더**에 있는지 확인하세요. ZIP을 풀지 않고 실행하면 이렇게 됩니다. 압축을 풀고 다시 실행하세요. |

| 메뉴는 뜨는데 `claude 를 못 찾음` | 설치 직후 흔합니다. **창을 닫고 키트를 다시 실행**하세요. |
| `[설치 실패] 인터넷 또는 보안 프로그램` | 인터넷을 확인하고, 백신·보안 프로그램이 막고 있는지 확인한 뒤 다시 시도하세요. |
| 글자가 네모로 깨짐 | 창 위쪽 오른쪽 클릭 → 속성 → 글꼴을 **맑은 고딕** 또는 **D2Coding**으로. Windows Terminal을 쓰는 것도 방법입니다. |

| `이 폴더는 Claude 로 처음 여는 곳이에요` 뒤 바로 꺼짐 | "믿나요?" 창에서 `No, exit`가 기본이라 Enter만 누르면 꺼집니다. **↓로 `Yes`를 고르고** Enter하세요. |
| 그래도 안 됨 | 메뉴 **1 설치하기**로 다시 설치해 보세요. |

### 14-2. 폴더 목록 문제

| 증상 | 원인과 해결 |
|---|---|
| `최근 작업한 기록을 못 찾았어요` | 아직 Claude Code를 켠 폴더가 없다는 뜻입니다. `D` 줄로 경로를 직접 붙여넣으세요. |
| 내가 쓰던 폴더가 목록에 없음 | Claude Code를 **그 폴더에서 켠 적이 없으면** 기록이 없습니다. `D`로 직접 입력하거나, 10장의 선택 기능을 설치하세요. |
| `cd`로 이동했는데 목록에 안 뜸 | 선택 기능이 설치되어 있는지, **새 세션**에서 시도했는지 확인하세요. 아래 14-3의 점검 명령을 실행해 보세요. |
| `S`를 눌러도 정렬이 안 바뀜 | 화살표·`S`는 입력이 연결된 창에서는 동작하지 않고 번호 입력 방식으로 바뀝니다. 일반 창(PowerShell·Windows Terminal)에서 실행했는지 확인하세요. |
| `그런 폴더가 없어요` | 경로 오타이거나 폴더가 지워졌습니다. 경로를 다시 확인하세요. |
| `그 폴더로 들어갈 수 없어요` | 목록을 만든 뒤 폴더가 지워졌거나 이름이 바뀐 경우입니다. 메뉴에서 다시 고르세요. |

### 14-3. 선택 기능(훅) 점검

`tools\cd-hook` 폴더에서 아래 명령을 실행합니다. **읽기만 하고 아무것도 바꾸지 않습니다.**

```
node check-cd-hook.cjs
```

- `[문제]` 줄이 있으면 그 문장대로 하세요. (`install-cd-hook.cmd`를 다시 실행하라는 안내가 많습니다.)
- 마지막의 `결과: 문제 없음`이 정상입니다. `[주의]`는 참고용입니다.
- `%APPDATA%\claude-code\cd-hook-errors.log`가 있으면 훅이 오류로 실패한 적이 있다는 뜻입니다. 그 안에는 오류 종류만 적혀 있습니다.
- 설치기가 `[중단]`을 보여 주면 이유가 적혀 있으며, 그때는 **아무것도 바꾸지 않았거나 원래대로 복구한 상태**입니다.
- `Node.js is required`가 나오면 Node.js를 설치하고 다시 실행하세요.

## 15. 자주 묻는 질문 (FAQ)

<details>
<summary>Q. 이 키트는 무료인가요? Claude Code도 무료인가요?</summary>

키트는 Apache License 2.0으로 **무료로** 쓸 수 있습니다. 하지만 **Claude Code는 무료가 아닙니다.** Pro·Max·Team·Enterprise·Console 계정 중 하나가 필요하고 무료 Claude.ai 플랜은 포함되지 않습니다. 요금은 Anthropic이 정합니다.

</details>

<details>
<summary>Q. 이 키트는 Anthropic이 만든 건가요? 안전한가요?</summary>

아닙니다. **비공식** 도우미이며 Anthropic과 무관합니다. 키트 코드는 공개되어 있어 누구나 읽어 볼 수 있고, 13장에 무엇을 하는지 적었습니다. "안전하다"고 보증하지는 않습니다. 사용은 사용자 책임입니다.

</details>

<details>
<summary>Q. Mac이나 휴대폰에서도 되나요?</summary>

키트는 **Windows 전용**입니다. Claude Code 자체는 다른 운영체제도 지원하지만(공식 문서 참고) 이 키트는 쓸 수 없습니다.

</details>

<details>
<summary>Q. Node.js나 Git을 꼭 설치해야 하나요?</summary>

아니요. 키트 본체와 Claude Code 설치에는 필요 없습니다. Node.js는 **선택 기능(10장)에만** 필요하고, Git은 있으면 Claude Code가 더 잘 동작하는 **선택 사항**입니다.

</details>

<details>
<summary>Q. 3번을 누르면 왜 폴더를 고르라고 하나요?</summary>

Claude Code는 **켠 폴더 안에서** 일하기 때문에, 처음부터 원하는 폴더에서 켜는 것이 가장 확실합니다. 폴더를 신경 쓰고 싶지 않으면 둘째 줄 `0 홈 폴더`를 고르면 됩니다. (맨 위 첫 줄은 `D 경로 직접 입력`입니다.)

</details>

<details>
<summary>Q. 왜 모든 디스크를 Claude에게 넘기나요? 끄고 싶어요.</summary>

Claude가 다른 드라이브의 파일도 다룰 수 있게 하려는 편의 기능입니다. 다만 **접근 범위가 넓어지는 만큼 신중해야 합니다**(13장). 끄는 스위치는 없습니다. 원하지 않으면 키트 [3] 대신 원하는 폴더에서 `claude`를 직접 실행하세요.

</details>

<details>
<summary>Q. 처음 여는 폴더에서 Claude가 그냥 꺼져 버려요.</summary>

"이 폴더를 믿나요?" 창의 기본 선택이 `No, exit`이기 때문입니다. **↓로 `Yes, I trust this folder`를 고르고 Enter**를 누르세요. (7-4 참고)

</details>

<details>
<summary>Q. 내 대화 내용이 키트를 통해 어딘가로 전송되나요?</summary>

키트 코드에는 대화·파일·계정 정보를 보내는 부분이 없습니다. 다만 **Claude Code는 Anthropic 서비스와 통신**하며, 그 처리는 Anthropic의 약관·개인정보 안내를 따릅니다. 회사 PC나 민감한 자료라면 소속 기관의 정책과 Anthropic 약관을 먼저 확인하세요.

</details>

<details>
<summary>Q. 회사에서 업무용(상업적)으로 써도 되나요?</summary>

키트 자체는 Apache-2.0에 따라 상업적으로도 쓸 수 있습니다. 하지만 **Claude Code의 업무·상업적 사용은 계정 종류에 따른 Anthropic 약관이 정합니다.** 이 문서는 그 가능 여부를 판단하지 않습니다. 18장의 링크에서 본인 계정의 약관을 직접 확인하세요.

</details>
