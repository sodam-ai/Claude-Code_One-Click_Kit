# Claude Code 원클릭 키트 (One-Click Kit)

> Windows에서 **클릭 한 번으로** Claude Code를 **설치·실행·관리**하는 한국어 도우미입니다.
> 컴퓨터·AI·전자기기를 **처음 다루는 분**도 따라 할 수 있게, 어려운 말은 최대한 풀어서 적었습니다.

## 1. 이게 뭔가요?

- **Claude Code** = 컴퓨터에서 **한국어로 시키면** 파일 정리·문서 요약·간단한 프로그램 만들기 같은 일을 **대신 해주는 AI 도구**입니다. (Anthropic 제작)
- **이 원클릭 키트** = Claude Code를 **어려운 명령어 없이 번호(메뉴)** 로 설치·실행·관리하도록 도와주는 작은 도우미입니다.
- 키트는 **2개의 파일**로 작동합니다:
  - `Claude-Code_One-Click_Kit.bat` — 더블클릭하는 **실행 파일**
  - `menu.ps1` — 한국어 메뉴 **본체** (실제 기능)
  - ⚠️ **이 두 파일은 반드시 같은 폴더에 함께** 있어야 합니다.

---

## 2. 빠른 시작 (3단계)

1. `Claude-Code_One-Click_Kit.bat` 를 **더블클릭**합니다.
2. **`1` 설치하기** 를 골라 Claude Code를 깝니다. *(처음 한 번만)*
3. **`3` 시작하기** 를 고르면 Claude가 켜집니다. 처음엔 **브라우저 로그인**이 한 번 뜹니다. → 끝!

그 뒤로는 그냥 한국어로 시키면 됩니다. 예) `이 폴더 정리해줘`

> 🖥️ **검은 창이 무서우면?** 마우스로만 쓰는 **데스크톱 앱**도 있어요 → [claude.com/download](https://claude.com/download)
> 명령어 없이 창에서 바로 쓸 수 있습니다. (유료 플랜/계정은 똑같이 필요)

## 3. 사전 준비물 / 필요 프로그램

### 꼭 필요한 것
| 항목 | 설명 |
|---|---|
| **운영체제** | Windows **10 (1809 이상)** 또는 **Windows 11** |
| **유료 플랜 또는 계정** | Claude **Pro** 또는 **Max** 구독, 또는 Anthropic **API** 계정 중 하나 |
| **인터넷 연결** | 설치·로그인·사용에 모두 필요 |
| **메모리/CPU** | RAM 4GB 이상, x64 또는 ARM64 |

> ❗ **무료 Claude.ai 계정만으로는 Claude Code를 사용할 수 없습니다.** (Anthropic 정책)

### 따로 설치할 필요 **없는** 것
- **Node.js · 개발 도구 · Git** → 설치 안 해도 됩니다. 공식 **네이티브 설치 방식**이 모든 걸 알아서 처리합니다.
- 키트가 쓰는 `PowerShell`·`curl`은 **Windows에 기본 내장**되어 있습니다.

### 선택 (있으면 좋은 것)
- **Git for Windows** — Claude Code가 일부 작업에서 더 잘 동작합니다. 없어도 정상 작동합니다.

## 4. 다운로드 방법

### (1) 이 키트 받기
- 키트는 파일 **2개**(`Claude-Code_One-Click_Kit.bat`, `menu.ps1`)와 문서로 구성됩니다.
- GitHub 등에서 받았다면 **압축을 풀고**, 위 두 파일이 **같은 폴더**에 있는지 확인하세요.

### (2) Claude Code 받기 (자동)
- 키트 메뉴 **`1` 설치하기** 를 누르면, **Anthropic 공식 주소**에서 자동으로 내려받아 설치합니다.
  - 공식 설치 스크립트: `https://claude.ai/install.ps1`
- 사용자가 별도로 무언가를 내려받을 필요가 없습니다.

## 5. 설치 방법

1. `Claude-Code_One-Click_Kit.bat` **더블클릭** → 메뉴가 뜹니다.
2. **`1` 설치하기** 선택 (↑↓로 고르고 Enter, 또는 숫자 `1` 키).
3. 안내를 읽고 **Enter** → 설치가 자동으로 진행됩니다. (1~2분)
4. `설치 완료!` 가 보이면 성공입니다.

> **이미 설치돼 있으면?** 키트가 자동으로 감지해 "이미 설치되어 있어요" 라고 알려주고, 재설치하지 않습니다.

### 수동 설치 (참고)
키트 없이 직접 설치하려면 PowerShell에서:
```powershell
irm https://claude.ai/install.ps1 | iex
```

## 6. 실행 방법

1. `Claude-Code_One-Click_Kit.bat` **더블클릭**.
2. 메뉴에서 **`3` 시작하기** 선택 → Claude Code가 켜집니다.
   - **폴더를 따로 묻지 않고** 곧바로 실행됩니다 (시작 위치: 내 사용자 폴더).
3. **처음 실행 시** 브라우저가 자동으로 열려 **로그인**을 요청합니다. 평소 쓰던 방식으로 로그인하면 됩니다.

> 끝낼 때는 Claude 안에서 **`/exit`** (또는 `/quit`) 를 입력하세요.

---

## 7. 사용 방법 (작동 원리)

- 로그인 후에는 **그냥 한국어로 시키면** 됩니다. 명령어를 외울 필요가 없습니다.
- 예시:
  - `이 폴더에 있는 사진들 날짜별로 정리해줘`
  - `간단한 메모장 프로그램 하나 만들어줘`
  - `이 파일이 무슨 내용인지 요약해줘`
- **작동 원리(간단히):** 키트(.bat)가 PowerShell 메뉴(`menu.ps1`)를 띄우고 → 메뉴가 공식 `claude` 명령을 실행합니다. 한국어 화면은 PowerShell이 담당해 글자 깨짐을 막습니다.

## 8. 메뉴 전체 설명

선택 방법: **↑↓ 화살표로 고르고 Enter**, 또는 **번호 키를 바로** 누르면 됩니다. 종료는 **`Q`**.

| 번호 | 기능 | 무엇을 하나요 |
|:---:|---|---|
| **1** | 설치하기 | Claude Code를 컴퓨터에 깝니다 (처음 한 번). 이미 있으면 건너뜀 |
| **2** | 로그인·계정 안내 | 어떤 계정이 필요한지, 로그인은 어떻게 하는지 안내 |
| **3** | 시작하기 | **바로 Claude 실행** (폴더 안 물어봄) |
| **4** | 도움말·명령어 | Claude 안에서 쓰는 명령어(`/help` 등) 보기 |
| **5** | 업데이트 | 최신 버전으로 맞추기 (`claude update`) |
| **6** | 진단·문제 해결 | 설치 상태 자동 점검 (`claude doctor`) + 자주 묻는 문제 |
| **7** | 버전 확인 | 설치된 버전 보기 (`claude --version`) |
| **8** | 제거 | 깔끔하게 지우기 (2단계 확인) |
| **Q** | 종료 | 키트 닫기 |

## 9. 명령어 모음

### Claude **안에서** 쓰는 명령어 (입력창에 입력)
| 명령 | 뜻 |
|---|---|
| `/help` | 모든 명령 보기 |
| `/exit` 또는 `/quit` | Claude Code 끝내기 |
| `/clear` | 대화를 새로 시작 (프로젝트 기억은 유지) |
| `/login` · `/logout` | 로그인 / 로그아웃 |
| `/status` | 현재 상태 보기 |
| `/usage` | 사용량·요금 확인 |

### 터미널에서 직접 쓰는 명령어 (참고용)
| 명령 | 뜻 |
|---|---|
| `claude` | Claude Code 실행 |
| `claude --version` | 설치된 버전 확인 |
| `claude update` | 최신 버전으로 업데이트 |
| `claude doctor` | 설치/설정 자동 점검 |

> 위 터미널 명령은 **키트 메뉴가 대신** 실행해 주므로, 초보자는 직접 칠 필요가 없습니다.

## 10. 전체 워크플로우

```
[ Claude-Code_One-Click_Kit.bat 더블클릭 ]
                │
                ▼
        ┌───────────────┐
        │   한국어 메뉴   │  ← menu.ps1
        └───────────────┘
   처음이라면:  [1] 설치 → [2] 로그인·계정 안내
   사용하기:    [3] 시작 → (처음엔 브라우저 로그인) → 한국어로 작업
   관리:        [5] 업데이트 / [6] 진단 / [7] 버전 / [8] 제거
```

1. **설치** `[1]` — 처음 한 번.
2. **로그인 안내 확인** `[2]` — 어떤 계정이 필요한지 미리 파악(선택).
3. **시작** `[3]` — Claude 실행. 처음엔 브라우저 로그인.
4. **사용** — 한국어로 시키기.
5. **관리** — 필요 시 업데이트·진단·제거.

---

## 11. 업데이트 방법

- 메뉴 **`5` 업데이트** 를 누르면 최신 버전으로 맞춰줍니다 (`claude update`).
- 사실 **네이티브 설치본은 평소에 자동으로 최신화**되므로, 가끔 한 번만 확인하면 충분합니다.

---

## 12. 제거 방법

1. 메뉴 **`8` 제거** 선택.
2. 둘 중 선택:
   - **[1] 프로그램만 지우기** — 설정·대화 기록은 남깁니다. (나중에 다시 쓸 수 있음)
   - **[2] 전부 지우기** — 설정·로그인·대화 기록까지 모두 삭제. **되돌릴 수 없습니다.**
3. "전부 지우기"는 실수 방지를 위해 **Y/N 한 번 더 확인**합니다.

> 지워지는 위치: 프로그램 `%USERPROFILE%\.local\bin\claude.exe`, 설정 `%USERPROFILE%\.claude` 및 `%USERPROFILE%\.claude.json`

## 13. 문제·오류 대처

가장 먼저 메뉴 **`6` 진단·문제 해결** 을 눌러보세요. 자동 점검(`claude doctor`)이 원인을 알려줍니다.

| 증상 | 해결 방법 |
|---|---|
| `claude 를 못 찾음` / `not recognized` | 검은 창을 **닫고** 키트를 **다시 실행** (설치 직후 자주 발생) |
| 로그인이 안 돼요 | 유료 플랜/계정이 맞는지, 인터넷이 되는지 확인 |
| 글자가 네모/깨짐 | 창 위쪽 우클릭 → 속성 → 글꼴을 **맑은 고딕** 또는 **D2Coding** 으로 |
| 설치가 실패해요 | 백신/보안 프로그램을 잠시 끄고 다시, 또는 인터넷 확인 |
| `menu.ps1 을 찾을 수 없음` | `.bat` 과 `menu.ps1` 이 **같은 폴더**에 있는지 확인 |
| 메뉴는 뜨는데 한글이 깨짐 | Windows Terminal 또는 글꼴 변경 (위 참고). PowerShell 기반이라 보통 정상 |

그래도 안 되면 메뉴 **`1` 설치하기** 로 다시 설치해 보세요.

## 15. 안전 안내

- 키트는 사용자의 개인정보를 **수집·전송하지 않습니다.** (로컬에서만 동작)
